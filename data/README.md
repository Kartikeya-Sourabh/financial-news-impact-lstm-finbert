# Data

This folder is intentionally empty in the repository.

Place the tweet dataset here as **`stock_tweets.csv`**. It should contain the columns
`Date`, `Tweet`, `Stock Name`, `Company Name` (25 tickers, about 80K tweets).

- Source: add the link to the public dataset you used (for example, a Kaggle "stock tweets" dataset).
- Before publishing, check the dataset's licence and do not re-upload it if redistribution is not allowed.
- The notebook writes `tweets_with_sentiment.csv` here; it is git-ignored.

AAPL price history is downloaded at run time with `yfinance`, so no price file is needed.
